# Falcor.Hub releases

Finished Falcor.Hub update files only. The source code is private.

- `latest.json`: the newest version, its notes, and every file's SHA-256.
- `packs/<version>/`: that version's update pack. Falcor.Hub downloads it by itself, checks every file and installs it when you press **Restart to update**.
- Installers are handed out directly; you need one only for a first install or when an update says a new installer is needed.
